Every block, on two pages

Control
repeat [10] timesRuns the blocks inside it that many times.
foreverRuns the blocks inside it again and again, until you stop it.
wait [1] secondsPauses. Half a second is 0.5.
when an object says [hello]Waits until another object says those words, then runs the blocks inside it.
when [the sun goes down]Waits for the sky: sunrise, midday, sunset, dark, or when the world opens.
duplicate [4] ft awayMakes a copy of this object, that far along.
Motion
move forward [2] feetJumps forward, the way the object is facing. A minus number goes back.
move up by [1] feetJumps straight up. A minus number goes down.
glide [10] feet over [2] seconds [smoothly]Moves forward slowly. Smoothly, straight or bouncy.
rotate [15] degreesTurns on the spot: left for a plus number, right for a minus one.
go back to startBack to where it was, the way it faced and the size it was, when the program began.
Look
say [Hello!]Shows a speech bubble for a few seconds. Listening objects hear it.
change size by [10] %Grows by that much. A minus number shrinks.
set size to [100] %Sets the size, compared with the size when the program began.
set opacity to [50] %100 is solid, 0 is invisible.
change color to [#e0455f]Paints the object. On a light orb, it changes the light too.
marker color [#e0455f]Picks the pen's colour.
marker downStarts drawing a line wherever the object goes.
marker upStops drawing.
erase all marksWipes every line in the world.
Four rules worth remembering
  • Blocks run in order, top to bottom.
  • Save runs the program. The green play button runs it again.
  • Forward is the way the object's front faces.
  • Turns that add up to 360 bring it back the way it started.
  1. Did you click Save?
  2. Read it out loud, one block at a time, and act it out. Where does it go wrong?
  3. Is each block inside the loop that should hold it, or outside?
  4. Do the words in say and when an object says match exactly?
  5. Is the model facing the way you think? Try rotate [180] degrees first.

Words to know

Block
One instruction in a program, which you drag into place.
Degrees
How far something turns. 360 degrees is all the way round.
Event
Something that happens, like a word being said or the sun going down, that a program can wait for.
Gizmo
The blue box, green ball and rings you use to stretch, lift and turn a shape.
Glide
Moving slowly from one place to another, instead of jumping.
Loop
Blocks that run more than once: repeat or forever.
Mental rotation
Turning a shape round in your head.
Model
Something in the world you can click, program and save.
Opacity
How solid something looks. Low opacity is see-through.
Piece
A shape that hasn't been rendered yet. It carries a hammer.
Program
A list of instructions a computer follows in order.
Render
Turning joined pieces into one finished model.
Sequence
Steps that happen one after another, in order.
Spatial reasoning
Thinking about shapes, space and where things are.
Tetrahedron
A pyramid with four triangle faces.
World Database
The website where Edusim worlds are shared.
World file
A small file holding a whole world, made by Save World.

For teachers and parents

This book is written for students about 8 to 13 to work through with Edusim open beside them, on their own or in pairs. It needs no programming experience from the adult running it.

PartClassroom timeWhat students learn
1 · Meet Edusim1 sessionMoving in 3D; what spatial reasoning is
2 · First projects3–4 sessionsExploring, photographing, saving and sharing
3 · Build it4–5 sessionsStretching, turning and combining shapes
4 · Code it4–5 sessionsSequences, loops, angles and events

A session is about 45 minutes.

  • Nothing to install, nothing to sign up for. Edusim runs in a web browser, including on Chromebooks. It has no accounts and collects no information about the people who use it.
  • Work stays on the computer it was made on, in the browser. Have students save a world file at the end of each session if they share machines.
  • Assessment is built in. Each part ends with a skills check, and the self-rating on page is meant to be filled in twice: once at the start, and again after Part 4.
Tips from the classroom
  • Clear World cannot be undone. Show students where it is on day one, and where Save World is.
  • Some people feel unwell watching moving 3D pictures. Settings, at the bottom of the Menu, turns motion effects down.
  • Let them get it wrong. A program that misbehaves is the lesson: ask what the computer did, and why.
