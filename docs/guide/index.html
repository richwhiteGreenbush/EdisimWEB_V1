The Hands-On Guide

Two skill cards and seven world cards. The skill cards teach the two things you do everywhere — building a model out of shapes, and programming it with blocks. The world cards each show you round one place and set you five coding challenges in it. Print one, print the lot, or just read them on screen.

Start here: the two skills

Neither of these belongs to any one world. Learn them once and you can use them in the park, on Mars, or inside somebody's lungs.

Skill card A

🔨 The Model Builder

Four shapes, one hammer icon and five buttons. Stretch, lift, paint, join, render — and whatever you were picturing is now a real object in the world.

  • Every handle and what it does
  • The mistakes everyone makes first
Skill card B

🧩 The Coding Blocks

Fifteen blocks in three colours. Drag them into a stack and anything in the world — including whatever you just built — starts doing what you said.

  • All fifteen blocks, with what each one is for
  • The by versus to rule that catches everybody

Want it as a walkthrough instead of a reference? The six build-along tutorials take you from a snowman to a self-copying robot, one step at a time.

How to use a world card

  1. Load the world. ☰ Menu → Load World → pick it. You land at the front gate.
  2. Go and find the boards. Two bright ⚡ ACTIVITY signs are standing in every world. The photos on the card show you where.
  3. Click the object the board names. A little menu opens. Choose Program.
  4. Drag the blocks together in the order shown, then hit Save. It starts straight away.
  5. Change one number and run it again. That is the whole skill, really.
  6. Then build something of your own and leave it there. Every world is a place to build in, not just to look at.

Stuck? A green ▶ floats above anything you have programmed — tap it to run the script again from the top.

The seven worlds

The Load World menu is short on purpose — The Park, The Moon, Dinosaur Island and The Taj Mahal — but every other world is a file away. Pick one from the shared gallery, download it, and open it with Load World File. My World is in there too: open grass and five trees, with three boards standing at the far side of it — what the place is for, a rocket to build, and the program to make it fly. It is the one to open when the thing you want to build needs room rather than scenery.
