Skill Card C

⚡ JavaScript Mode

The same programs you build with blocks, written as real code. Flip one switch and every block you know becomes a line you can type.

Getting there: click any object, choose Program, and press the Block CodeJavaScript switch at the top of the panel. Your blocks appear as code. Type, press Save, and it runs right away. Flip back any time — nothing is lost in either direction.

Three rules, and that's the whole language

  1. 1 · Put await in front of every action

    await means "do this, then go on to the next line". It is what makes your program run one step at a time instead of all at once.

    await rotate(90); await wait(1); await moveForward(10);

  2. 2 · Loop with forever() and repeat()

    These are Edusim's own loops, and they are polite: they let the rest of the world keep running between turns. A plain while (true) does not — it freezes the page.

    await forever(async () => { await rotate(15); });

  3. 3 · Save checks your code first

    If you typed something the computer cannot read, Save tells you what is wrong and keeps the editor open. Nothing is saved and nothing is lost. Fix it, or flip back to blocks.

Every action you can await

Same three families as the blocks, same colours in the editor. Numbers are feet, seconds, degrees or percent — the same units the blocks use.

M

Motion

Where things go

  • moveForward(feet)
  • moveUp(feet) · negative goes down
  • glide(feet, seconds) · smooth
  • rotate(degrees)
  • goBackToStart()

💡 moveForward and glide follow the way the object is pointing, so a rotate before them genuinely steers. glide is the smooth one — give it seconds and it spends them.

C

Control

When and how often

  • wait(seconds)
  • repeat(times, fn)
  • forever(fn)
  • whenSaid('word', fn) · a listener
  • duplicate(feet)

💡 whenSaid registers and waits. It runs its function every time anything in the world says that word — which is how two objects work together. Copies made by duplicate keep their whole program but their own duplicate() does nothing, so copies never breed.

L

Looks

What things look like — and say

  • say('words')
  • changeSize(percent)
  • setSize(percent)
  • setOpacity(percent)
  • changeColor('#ff5a12')
  • markerColor('#00c2ff')
  • markerDown() / markerUp()
  • eraseAllMarks()

💡 Words go in quotes: say('hello'), changeColor('#3fb37f'). The marker draws a 3D line behind the object wherever it goes — put the marker down, drive a square, and the square is drawn on the world.

Type these four first

  1. Spin forever

    The one-line classic. Change the 15 and the speed changes.

    await forever(async () => { await rotate(15); });

  2. Drive a square

    Four sides, four right turns. 360 ÷ 4 = 90, so it ends exactly where it started.

    await repeat(4, async () => { await glide(8, 2); await rotate(90); });

  3. A heartbeat

    setSize measures from the size the object started at, so this beats steadily forever instead of slowly growing.

    await forever(async () => { await setSize(115); await wait(0.4); await setSize(100); await wait(0.4); });

  4. Two objects talking

    Put the first program on one object and the second on another. The word carries the signal.

    // object one: await say('go'); // object two: whenSaid('go', async () => { await glide(20, 3); });

🤯 Worth knowing

Blocks and JavaScript are two views of one program. Build with blocks, flip the switch, and your blocks appear as code you can read. Edit the code and it is yours — your blocks are still saved behind the other tab, and switching never deletes either one. The fastest way to learn is to build something with blocks first, then go and read what it says in JavaScript.
