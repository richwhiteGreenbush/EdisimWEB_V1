🔨 Build

Four shapes. Endless models.

Open Menu → Create Model and drop a shape on the ground — a cube, a sphere, a cylinder or a pyramid. A little 🔨 hammer floats over it. The hammer is the whole toolbox: click it and you can stretch the piece, turn it, paint it, and join it to its neighbours.

  1. ✥ Stretch to Shape
    1

    Stretch it into shape

    Choose Stretch to Shape and drag a corner. A cube becomes a wall, a plank or a whole roof — and the opposite corner stays put, so nothing drifts.

    🔄 Rotate/Move Shape adds rings for turning. Turns snap every 15°, so square corners are actually square.

  2. ✥ Move
    2

    Lift it into place

    Drag the green ball above the box to move a piece anywhere — up, down, sideways. That is how a head goes on a body and a roof goes on a house.

  3. 🔗 Nine pieces
    3

    Join the pieces

    Connect to Primitive lists only the pieces touching this one. Tap to join them, and paint each with Apply Texture — a colour, or a picture.

  4. ✨ One model
    4

    Press Render Model

    The hammers vanish and the pile of parts becomes one solid thing you can resize, program, save and copy.

    🆕 Got your own 3D models? Import a .glb file and it gets the hammer too.

🧩 Code

Two ways to write the same program

Click anything in any world and press Program. Start with drag-and-drop blocks. When you are ready, flip the switch to JavaScript — your blocks turn into real code you can read. Flip back any time. Nothing is ever lost.

Block Code

Snap blocks together

🧩 Program this object

Fifteen blocks in three colours: Control (repeat, forever, wait), Motion (move, glide, rotate) and Looks (say, size, colour). If you have met Scratch, you already know how this works.

forever move forward 10 feet rotate 90 degrees
JavaScript

Or type real code

Block CodeJavaScript 
// the same program, as code
await forever(async () => {
  await moveForward(10);
  await rotate(90);
});

The exact same actions, written out. Every block has a matching function, and the editor colours your code as you type. If you make a typo, Save tells you what is wrong instead of losing your work.

▶ Every programmed object gets a green play button floating above it. Programs save with the world and start themselves the next time you open it.

🔬 Research-based practices

A research-based learning tool for kids

Edusim is built on one of the strongest findings in learning science: spatial reasoning — picturing, turning and building things in your mind — predicts success in science and math for decades, it's highly trainable, and it grows fastest in hands-on 3D environments with coding. That's not our hunch; it's what meta-analyses spanning hundreds of studies measured. Our Research Library walks through the evidence in plain language and shows how each finding became an Edusim feature.

What Edusim deliberately does not do

There are no accounts, so there is no teacher dashboard, no rostering and no cross-device save — and no student data is collected, ever. Students save work in the browser and hand it in as a file.

That is the whole trade. It is why there is nothing for a technology department to approve, nothing to purchase, and no consent form — and why a teacher can use it tomorrow morning without asking anyone.
